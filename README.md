# NexaAI - Premium AI SaaS Landing Page ✦

NexaAI is a high-performance, visually stunning landing page for a fictional AI-powered workspace. Designed with a modern, "ultra-clean" aesthetic inspired by industry leaders like OpenAI, Vercel, and Linear, this project showcases advanced CSS techniques, smooth animations, and interactive vanilla JavaScript components.

![Landing Page Preview](https://via.placeholder.com/1200x630/06060a/f0f0ff?text=NexaAI+2.0+Preview)

## 🚀 Key Features

- **Animated Aurora Background**: A fluid, CSS-only aurora mesh background using radial gradients and keyframe animations.
- **Dynamic Word-Swap Hero**: A high-impact headline that cycles through value propositions with smooth opacity transitions.
- **Interactive Live Chat Demo**: A functional "See it think" section featuring prompt chips and a typewriter-effect AI response system.
- **Bento Grid Layout**: A responsive 12-column bento grid showcasing features with staggered scroll-reveal animations.
- **Monthly/Yearly Pricing Toggle**: A custom-built pricing switcher that updates rates and badges dynamically via JavaScript.
- **Premium UX/UI**:
  - Glassmorphism navigation bar with backdrop-filter.
  - Infinite marquee for social proof.
  - Smooth-scroll accordion FAQ.
  - Fully responsive design optimized for all device sizes.
  - Intersection Observer API for performance-focused entrance animations.

## 🛠️ Technology Stack

- **HTML5**: Semantic structure for SEO and accessibility.
- **CSS3 (Vanilla)**: Custom properties (variables), Flexbox, CSS Grid, and sophisticated animations.
- **JavaScript (Vanilla)**: Interaction logic, DOM manipulation, and typewriter effects (Zero dependencies).
- **Typography**: Inter (via Google Fonts).
